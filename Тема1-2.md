Тема 1-2: Основи архітектури та безпеки ПК
1. Правила електробезпеки при роботі з внутрішніми компонентами ПК
Робота з "залізом" вимагає суворого дотримання правил, щоб уникнути ураження струмом або пошкодження електроніки:

Повне знеструмлення: Завжди вимикайте блок живлення фізичною кнопкою на ньому та витягуйте кабель із розетки.

Залишковий заряд: Після вимкнення живлення натисніть і утримуйте кнопку ввімкнення ПК протягом 5-10 секунд. Це розрядить конденсатори.

Антистатика: Статична електрика від тіла може "пробити" мікросхему. Рекомендується використовувати антистатичний браслет або хоча б торкнутися металевої частини корпусу перед роботою з компонентами.

Правильне поводження: Тримайте плати (ОЗП, відеокарти) тільки за краї. Не торкайтеся контактних доріжок, оскільки волога та жир з пальців викликають корозію.

2. Форм-фактори корпусів настільних комп'ютерів
Форм-фактор визначає фізичні розміри корпусу та сумісність із материнськими платами:

Full Tower (Повна вежа): Найбільші корпуси (висота від 60 см). Вони мають найбільше місця для охолодження, великої кількості дисків та професійних материнських плат формату E-ATX. Використовуються для серверів та потужних ігрових станцій.

Mid Tower (Середня вежа): Найбільш універсальний та популярний формат. Він підходить для стандартних плат ATX та Micro-ATX. Це золота середина для більшості домашніх та ігрових комп'ютерів.

Mini Tower (Мала вежа): Компактні корпуси для плат формату Micro-ATX. Зазвичай використовуються в офісах або бюджетних домашніх системах, де важливо заощадити місце на столі.

SFF (Small Form Factor): Дуже маленькі корпуси для плат Mini-ITX. Вони ідеальні для створення міні-ПК або медіа-центрів під телевізор, але вимагають дуже продуманого охолодження.

3. Блок живлення (PSU)
Блок живлення — це вузол, що забезпечує стабільну напругу для кожного компонента.

Основні характеристики:

Потужність: Вимірюється у Ватах (Вт). Для звичайного ПК достатньо 500-600 Вт, для потужних систем — від 750 Вт.

ККД (80 Plus): Маркування, що вказує на якість БЖ (Bronze, Silver, Gold тощо). Чим вищий рівень, тим менше енергії витрачається на нагрівання самого блоку.

Основні конектори:

Main 24-pin: Головний кабель для материнської плати.

CPU 4/8-pin: Живлення для процесора.

PCI-e 6/8-pin: Живлення для відеокарти.

SATA: Для живлення накопичувачів (SSD/HDD).

4. Основні компоненти материнської плати
На материнській платі розміщені всі ключові вузли, що забезпечують роботу системи:

Процесорний роз'єм (Socket): Місце встановлення "мозку" комп'ютера.

Слоти ОЗП (RAM slots): Роз'єми для встановлення оперативної пам'яті.

Слоти розширення PCIe: Використовуються для відеокарт, мережевих або звукових карт.

Чіпсет: Набір мікросхем, що координує роботу всіх підключених пристроїв.

Роз'єми живлення: Місця підключення кабелів від блоку живлення.

Батарейка CMOS: Маленька батарейка, яка не дає скидатися налаштуванням часу та BIOS після вимкнення ПК.

SATA/M.2 порти: Роз'єми для підключення накопичувачів даних.
